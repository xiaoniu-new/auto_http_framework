【接口名称】假期申请提交
【所属业务域】hr
【所属子系统】leave
【请求方式】POST
【接口路径】/hr/leave/apply

====请求信息====
Headers:
Content-Type: application/json

Request Body(json):
{
    "startDate":"2026-09-01",
    "endDate":"2026-09-03",
    "leaveType":"annual",
    "reason":"个人休假"
}

====成功响应====
{
    "code":0,
    "msg":"success",
    "data":{
        "leaveId":"LV20260901001",
        "status":"pending"
    }
}

====异常响应参考（可选）====
startDate为空：
{
    "code":40001,
    "msg":"开始日期不能为空",
    "data":null
}

【业务特殊规则】开始日期不能晚于结束日期
